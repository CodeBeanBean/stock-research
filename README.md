# Stock Research

这是一个按公司长期维护的股票研究项目。每家公司使用独立档案目录，保留研究结论、财务模型、来源索引、原始披露和更新记录，便于后续财报发布时做增量更新，而不是重复从零开始。

估值与报告入口见 [股票研究估值总览](stock-overview.md)。

跨会话接续和项目长期约定见 [项目长期上下文](PROJECT_CONTEXT.md)。Codex 启动规则保存在本目录及工作区根目录的 `AGENTS.md`。

## 目录约定

```text
stock-research/
├─ companies/<company>/
│  ├─ company-profile.md       # 公司与治理档案
│  ├─ research-report.md       # 当前基本面研究结论
│  ├─ financial-model.xlsx     # 可复核财务与估值模型
│  ├─ source-index.md          # 来源、口径与审计说明
│  ├─ update-log.md            # 研究变更记录
│  └─ source-documents/        # 官方披露原件
└─ outputs/<research-run>/     # 每次研究运行的模型与验收文件
```

## 更新原则

1. 财务事实优先使用交易所公告、经审计年报和公司正式业绩材料。
2. 市场价格与汇率注明日期、币种和数据接口。
3. 事实、假设与判断分开记录；估值至少包含熊市、基准和牛市情景。
4. 每次财报后先更新来源和模型，再更新结论及证伪条件。
5. 对自由现金流、资本开支、股份变化和一次性项目做持续跟踪。
