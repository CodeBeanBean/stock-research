# Stock Research

这是一个按公司长期维护的股票研究项目。每家公司使用独立档案目录，保留研究结论、财务模型、来源索引、原始披露和更新记录，便于后续财报发布时做增量更新，而不是重复从零开始。

估值与报告入口见 [股票研究估值总览](stock-overview.md)，亦可在浏览器中打开交互版看板 [stock-overview.html](stock-overview.html) 进行实时排序、多维筛选和安全边际区间对比。

跨会话接续和项目长期约定见 [项目长期上下文](PROJECT_CONTEXT.md)。Codex 启动规则保存在本目录及工作区根目录的 `AGENTS.md`。

**三季报核查（2026-10-15晚间）：** 已逐家核对36家公司，除已更新的赣锋外未检出新的完整三季报；达势、龙湖、春秋的经营补充及福寿园复牌进展见[核查与增量分析](quarterly-disclosure-review.md)，[永久留档](research-history/index.md)。各公司价格和估值日期未统一刷新。

## 目录约定

```text
stock-research/
├─ companies/<company>/
│  ├─ company-profile.md       # 公司与治理档案
│  ├─ research-report.md       # 当前基本面研究结论
│  ├─ financial-model.xlsx     # 可复核财务与估值模型
│  ├─ source-index.md          # 来源、口径与审计说明
│  ├─ update-log.md            # 研究变更记录
│  ├─ source-documents/        # 官方披露原件
│  └─ research-history/       # 每次研究的永久留档及版本索引
├─ scripts/
│  ├─ sync_overview.py         # 自动从 Markdown 提取数据并更新交互看板
│  └─ server.py                # 启动本地服务（支持网页端一键触发同步）
├─ stock-overview.md           # 静态估值总览和报告导航
├─ stock-overview.html         # 交互式估值看板网页
└─ outputs/<research-run>/     # 每次研究运行的模型与验收文件
```

### 研究报告留档

公司根目录保留最新版入口，每次完成首次研究、财报更新、估值修订或实质报告补充后，在 `research-history/YYYY-MM-DD_vNNN_topic/` 封存一版。例如 `2026-09-05_v001_2026h1-initial`、`2026-10-15_v002_2026q3-update`。日期采用已知研究日期，公司内版本号递增，同日更新分别编号；实际封存/恢复时间另行记录，旧稿日期未知时明确标注。

每版保存当时的报告、对应模型、公司档案、来源索引和更新记录（存在时），以 `research-summary.json` 保存关键研究事实、估值和变化，以 `manifest.json` 记录日期、封存方式、来源和校验摘要。结论不变也留档，再次覆盖前先保护旧版；历史错误由后续版本解释和纠正。

历史分为三页：`index.md`比较历次参考价、Bear/Base/Bull、基准空间、判断和重点变化；`research-notes.md`展开每次重要信息、估值假设、前后输入与调整原因/影响、风险和后续验证；`versions.md`保存日期、恢复方式、实际归档时间及审计导航。历史摘要使用当时信息，价格变化、经营变化、估值假设调整及旧稿错误修正分别说明。

原始披露集中在 `source-documents/`，内容变化时另存新文件名。历史报告链接自动修正，引用原件记录校验摘要，模型按原字节复制。`outputs/` 继续保留生成与验收产物。

现有示例：[赣锋估值与判断演变](companies/ganfeng-lithium/research-history/index.md)、[研究要点及变化](companies/ganfeng-lithium/research-history/research-notes.md)、[版本登记](companies/ganfeng-lithium/research-history/versions.md)。归档由 `equity-research` 附带的 `archive_research.py` 完成和校验，缺失历史只从真实文件恢复并标明来源。目录规范迁移保留旧树备份、原manifest摘要与原封存时间，不改旧研究结论或模型。

### 看板数据同步与本地服务

- **命令行同步**：在终端运行 `python scripts/sync_overview.py`，自动从各公司报告和总览提取最新估值并刷新 `stock-overview.html`。
- **网页端一键同步**：运行 `python scripts/server.py`（或在网页上点击“复制命令”），浏览器访问后点击页面顶部的 **【🔄 同步数据】** 按钮即可直接触发同步，无需切回终端。

## 更新原则

1. 财务事实优先使用交易所公告、经审计年报和公司正式业绩材料。
2. 市场价格与汇率注明日期、币种和数据接口。
3. 事实、假设与判断分开记录；估值至少包含熊市、基准和牛市情景。
4. 每次财报后先更新来源和模型，再更新结论及证伪条件。
5. 对自由现金流、资本开支、股份变化和一次性项目做持续跟踪。
